# LaMP Motion Expert

Official CogVideoX-based Motion Expert checkpoint used by LaMP. The checkpoint
contains the `motion_head.*` weights for motion inference and Stage 2
initialization.

This is not a complete action policy. See the
[LaMP repository](https://github.com/SummerWXK/LaMP) for usage and Stage 2
training instructions.
